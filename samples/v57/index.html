The Power of the Abstracted Table Layer

Callers no longer construct AST trees, chain instructions, or import catalog specs. A single invocation handles spec resolution, DOM mounting, and event delegation: 

// 1-Line Table Generation
render({
    data,
    columns,
    targetHtmlId: "container",
    type: "table.simple",
    appendPosition: "replace",
    classToApply: ""
});

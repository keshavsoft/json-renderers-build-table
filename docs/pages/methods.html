Architecture Guide Building Tables with Different Methods

Methods for Constructing Tables

Explore the flexible integration patterns supported by json-renderers-build-table: from one-liner declarative rendering to the decoupled event contract and raw spec pipelines.

Method 1: Direct render() Method 2: Two-Step Contract Method 3: CDN / Vanilla JS Method 4: buildTableSpec() Method 5: Modular Primitives
1

High-Level render() API

The primary declarative entry point for single-call table construction.

The render() function takes your JSON data and columns, validates the schema with json-renderers-guard, runs the transformation instructions via json-renderers-run-instructions, and mounts native DOM nodes into the target element using @keshavsoft/json-to-dom. 

import { render } from "json-renderers-build-table";

const columns = [
  { columnName: "id", label: "ID" },
  { columnName: "name", label: "Product Name" },
  { columnName: "price", label: "Unit Price ($)" }
];

const data = [
  { id: 101, name: "Precision Hex Bolt", price: 0.45 },
  { id: 102, name: "Flange Nut M8", price: 0.28 }
];

// Mounts the complete semantic table directly into #table-container
render({
  data,
  columns,
  targetHtmlId: "table-container",
  type: "simple",
  options: {
    showSerial: true,
    showOptions: false
  }
});
Supported type values: simple withFooter withSearchAndFooter headerOnly bodyOnly footerOnly
2

The Two-Step Decoupled Contract

Pure rendering followed by decoupled container event delegation.

In dynamic dashboards, typing in a search bar usually blows away the DOM and destroys input focus if the whole table re-renders. With the Two-Step Contract, Step 1 performs pure layout rendering, and Step 2 registers domain event delegation via json-renderers-build-table-events. 

import { render, hookEvents } from "json-renderers-build-table";

// STEP 1: Pure Layout & Structure Rendering
render({
  data: myDataset,
  columns: myColumns,
  targetHtmlId: "dom-render-container",
  type: "withSearchAndFooter",
  options: { showSerial: true, showOptions: true }
});

// STEP 2: Non-invasive Event Delegation
// Container listener catches bubbling events and only repaints tbody!
hookEvents({
  container: "dom-render-container",
  dataset: myDataset,
  columns: myColumns,
  onSearch: (query, filteredRecords) => {
    console.log(`Filtered ${filteredRecords.length} records matching "${query}"`);
  },
  onRowClick: (record) => {
    console.log("Selected row:", record);
  },
  onRowAction: (actionType, record) => {
    console.log(`Action [${actionType}] triggered on:`, record);
  },
  onSave: (newRecord) => {
    console.log("Saving new row from footer input:", newRecord);
    myDataset.push(newRecord);
  }
});
Key Advantage: Because hookEvents delegates at the container root, your search bar never loses caret focus when filtering 10,000+ records!
3

Browser CDN / Vanilla JavaScript

Zero npm installation, zero bundlers, 100% browser-native execution.

Every build publishes a self-registering UMD/ESM bundle under the window.ks.jsonRenderers.build.table global namespace. 

<!-- Load Bootstrap for styling -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet" />

<!-- Container for your table -->
<div id="table-container" class="container py-4"></div>

<!-- Load json-renderers-build-table CDN bundle -->
<script type="module" src="https://keshavsoft.github.io/json-renderers-build-table/dist/v55/min.js"></script>

<script type="module">
  const data = [
    { code: "A1", description: "Stainless Steel Bolt", qty: 250 },
    { code: "A2", description: "Spring Washer M10", qty: 1500 }
  ];

  const columns = [
    { columnName: "code", label: "Code" },
    { columnName: "description", label: "Description" },
    { columnName: "qty", label: "Quantity" }
  ];

  // Global namespace execution
  window.ks.jsonRenderers.build.table.render({
    data,
    columns,
    targetHtmlId: "table-container",
    type: "simple"
  });
</script>
4

Direct Spec Generation with buildTableSpec()

Generate pure JSON AST specifications for testing, caching, or custom rendering.

If you want to inspect the generated Abstract Syntax Tree (AST) before mounting or if you need Server-Side Rendering (SSR) without a browser DOM, use buildTableSpec() directly: 

import { buildTableSpec } from "json-renderers-build-table/src/v55/buildTableSpec.js";

// Produces a pure JSON AST representation of the table
const spec = buildTableSpec({
  type: "withFooter",
  data: dataset,
  columns: columns,
  options: {
    showSerial: true,
    showOptions: true
  }
});

console.log("Generated JSON Table AST:", JSON.stringify(spec, null, 2));
// Output: { tagName: "table", class: "table table-bordered", children: [...] }
5

Modular Instruction Pipeline

Direct composition of decoupled foundation packages.

For maximum control or building custom component transformers, you can orchestrate the individual ecosystem packages directly: 

import guardFunc from "json-renderers-guard";
import runInstructions from "json-renderers-run-instructions";
import jsonToDom from "@keshavsoft/json-to-dom";
import { hookTableEvents } from "json-renderers-build-table-events";

// 1. Guard input contracts
guardFunc({ data, columns, targetHtmlId: "my-table" });

// 2. Run declarative 1D & 2D instruction blueprints
const spec = runInstructions({
  instructionMainKey: "table",
  instructionSubKey: "simple",
  data: { data, columns },
  options: { showSerial: true }
});

// 3. Hydrate into native DOM nodes
jsonToDom({
  jsonSpec: spec,
  targetHtmlId: "my-table"
});

// 4. Hook container-level event delegation
hookTableEvents({
  container: "my-table",
  dataset: data,
  columns
});

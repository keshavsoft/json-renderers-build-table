Interactive Showcase Table Variants & Live Examples

Table Examples: simple, headerOnly, bodyOnly, footerOnly

Explore table variants rendered on demand through declarative specifications. Each variant serves targeted UI composition needs — from standalone header bars to streaming body rows.

1. Simple Table 2. Header Only 3. Body Only 4. Footer Only 5. Full with Footer & Search
Type: "simple"

1. Simple Table

Standard semantic table containing complete columns header (<thead>) and dataset rows (<tbody>).

Live Render Output:
Click "Run Live Render" or load page to render
render({
  data: [
    { itemCode: "ITM-01", description: "M10 Stainless Bolt", category: "Fasteners", stock: 120 },
    { itemCode: "ITM-02", description: "Galvanized Hex Nut", category: "Hardware", stock: 450 },
    { itemCode: "ITM-03", description: "Heavy Duty Anchor", category: "Masonry", stock: 85 }
  ],
  columns: [
    { columnName: "itemCode", label: "Item Code" },
    { columnName: "description", label: "Description" },
    { columnName: "category", label: "Category" },
    { columnName: "stock", label: "In Stock" }
  ],
  targetHtmlId: "container-simple",
  type: "simple",
  options: { showSerial: true, showOptions: false }
});

3. Body Only

Renders strictly the <tbody> rows from the dataset. Used for infinite scrolling, dynamic row appending, and lightweight table updates without recreating the table container.

Live Render Output:

5. Full Interactive Table with Footer & Search

The complete production configuration: includes live search filtering, row action buttons, serial numbers, and footer row inputs with non-destructive focus.

Live Render Output:
Click "Run Live Render" to inspect full withFooter table
import { render, hookEvents } from "json-renderers-build-table";

render({
  data: inventoryData,
  columns: inventoryColumns,
  targetHtmlId: "container-withFooter",
  type: "withFooter",
  options: { showSerial: true, showOptions: true }
});

hookEvents({
  container: "container-withFooter",
  dataset: inventoryData,
  columns: inventoryColumns,
  onSearch: (q, filtered) => console.log("Filtering inventory:", q),
  onRowClick: (record) => console.log("Clicked:", record),
  onSave: (newRec) => {
    alert("New record added: " + JSON.stringify(newRec));
  }
});

V55 Pure Declarative HTML Table Rendering

Build HTML Tables from Data
Declaratively in Pure JSON

Zero imperative DOM loops. Zero hardcoded markup. Supply your dataset and column definitions, and let the builder stamp out a clean, semantic HTML table.

$ npm install json-renderers-build-table

The Pure Table Contract

A single, clean responsibility: turn structured data into DOM elements.

1. WHAT YOU SUPPLY
Data + Columns + Target

No HTML strings or manual loops. Describe your schema and data:

const columns = [
  { columnName: "itemName", label: "Item Name" },
  { columnName: "category", label: "Category" },
  { columnName: "baseUnit", label: "Unit" }
];

const data = [
  { itemName: "High Tensile Bolt", category: "Fasteners", baseUnit: "kgs" },
  { itemName: "Wire Coil", category: "Raw Materials", baseUnit: "kgs" }
];
2. WHAT YOU GET
Rendered Table in the DOM

One single render function call mounts the entire table structure:

import { render } from "json-renderers-build-table";

render({
  data,
  columns,
  targetHtmlId: "table-container",
  type: "withSearchAndFooter",
  options: {
    showSerial: true,
    showOptions: true
  }
});
Decoupled Ecosystem

Specialized Repositories

Rather than building a monolithic library, each concern is isolated into its own dedicated, focused repository.

Rendering Repo →
json-renderers-build-table

Owns pure table structure and JSON-to-DOM specification. Zero event coupling, pristine single responsibility.

Interactivity Repo →
json-renderers-build-table-events

Owns container-level event delegation (search, row click, options, footer save) driven by bindings.json and feature-folders.

Traversal Repo →
dom-traversal-functions

Standardized table navigation (Header, Body, Footer) powered by declarative instructions.json via dom-primitive-engine.

How They Connect: Pure Rendering + Separate Events

To achieve interactivity without polluting the rendering pipeline or destroying search input focus: 

import { render, hookEvents } from "json-renderers-build-table";

// STEP 1: Pure Rendering (stamps out the structure)
render({
  data: dataset,
  columns,
  targetHtmlId: "dom-render-container",
  type: "withSearchAndFooter",
  options: { showSerial: true, showOptions: true }
});

// STEP 2: Hook Domain Events (wires interactivity powered by json-renderers-build-table-events)
hookEvents({
  container: "dom-render-container",
  dataset,
  columns,
  onSearch: (query, filtered) => console.log("Filtering:", query),
  onRowClick: (record) => console.log("Selected row:", record),
  onRowAction: (action, record) => console.log(action, record),
  onSave: (newRecord) => console.log("Saved footer row:", newRecord)
});
